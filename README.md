# Task 3 - Infrastructure as Code with Terraform

## Objective
Provision a local Docker container using Terraform.

## Tools Used
- Terraform
- Docker
- Nginx

## What I Did
1. Configured Docker provider in Terraform.
2. Created Nginx Docker image resource.
3. Created Nginx Docker container.
4. Used terraform init.
5. Used terraform plan.
6. Used terraform apply.
7. Checked Terraform state.
8. Verified the Nginx application.
9. Destroyed the infrastructure using terraform destroy.

## Terraform Commands Used

terraform init
terraform fmt
terraform validate
terraform plan
terraform apply
terraform state list
terraform destroy
